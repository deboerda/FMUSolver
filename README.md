# FMUSolver

FMU（Functional Mock-up Unit / FMI）协同仿真运行与可视化控制工具，面向**工业数字孪生**与**航空航天相邻（非密）**能源 / 轨道类模型的通用演示与联调。

> 公开说明：本文档已去除雇主、客户与内部型号信息。若本仓库含完整客户交付物，**建议改为 Private**。

## 功能概览

- 加载并运行标准 FMI 2.0 FMU
- 实时仿真控制（开始 / 暂停 / 继续 / 停止、参数热更新）
- 轨道 / 能源类离线预计算（通用演示）
- UDP + Protobuf 将仿真变量转发到三维视景或本地看板
- 可选：外部遥测类 UDP 数据桥接与变量名映射（配置驱动，无硬编码业务）

