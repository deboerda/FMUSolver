# [SKILL] FMU 仿真平台 Word 文档导出与排版标准作业流程 (SOP)

> [!IMPORTANT]
> 当用户或开发流程要求“生成说明书 Word 版”、“转换文档格式”或“导出项目文档为 DOCX”时，AI 必须严格执行此流程。

## 1. 目标与适用范围
本 Skill 旨在将仿真平台的所有 Markdown 格式技术报告和用户手册（如《使用操作和维护说明书》）自动转换为排版精美、格式规范的 Microsoft Word (`.docx`) 文档，便于现场交付、打印和签字盖章。

## 2. 依赖环境与组件
本工具依赖第三方 Python 库进行纯文本解析与 Word 二进制文件流生成：
*   **依赖库**: `python-docx`
*   **转换器源码**: `c:\Spaceship\FMUSOLVER\Script\markdown_to_docx.py`
*   **支持的 Markdown 语法特性**:
    - `#` 至 `######` 分级标题自动对应 Word 的级联 Heading
    - `**加粗**`、`*斜体*`、`***粗斜体***`、`\`行内代码\`` 行内样式
    - 无序列表（`-`, `*`, `+`）与有序列表（`1.`, `2.`）
    - 代码块（带左侧灰色竖线及浅灰背景着色）
    - 引用块与 GitHub 风格 Alert 提示框（`[!NOTE]`, `[!TIP]`, `[!WARNING]`, `[!CAUTION]`，带对应警示色侧边边框与淡背景色）
    - Markdown 矩阵表格（自动转换为 Word 轻量级网格表格，表头加粗白字配深绿背景，交替行浅灰背景，隐去纵向边框）

## 3. 使用操作命令

### 3.1 默认智能转换模式（首选）
若不指定参数运行，工具会自动在当前目录及上级目录搜索《使用操作和维护说明书》并将其转换为 Word 文档。若找不到该文件，则会批量将当前目录下所有的 `.md` 文件转换：
```bash
# 在 Script 目录下执行
python markdown_to_docx.py
```

### 3.2 指定文件转换模式
若需要转换特定的技术文档：
```bash
# 格式：python markdown_to_docx.py <输入Markdown文件路径> [输出Word文件路径]
python markdown_to_docx.py input_report.md output_report.docx
```

## 4. 样式规范说明（样式自动配置）
转换器内部已预先配置了专业的中文排版样式，禁止随意修改，如需调整需通过 XML 操纵库修改：
*   **正文字体**: 微软雅黑 (Microsoft YaHei)，大小 `10.5` 磅 (约五号字)，颜色为深灰色 (`#333333`，避免纯黑刺眼)。
*   **一级标题**: 微软雅黑 `18` 磅 (约三号字) 加粗，主题色为深蓝色 (`#0D47A1`)，段前空 `14` 磅。
*   **二级标题**: 微软雅黑 `14` 磅 (约四号字) 加粗，主题色为深绿色 (`#1B5E20`)，段前空 `14` 磅。
*   **表头样式**: 微软雅黑加粗白字，填充背景为深绿色 (`#1B5E20`)，左右间距自动调整。
*   **交替行背景**: 单数数据行填充为超浅灰色 (`#F9F9F9`)。

## 5. 常见故障排除
*   **异常 1：`ImportError: No module named 'docx'`**
    - 解决方案：当前 Python 环境缺少依赖库，请执行 `pip install python-docx` 后重新运行。
*   **异常 2：转换后表格纵向线杂乱**
    - 解决方案：本项目转换表格采用现代扁平化无纵向框设计，若外部导入 Word 模板产生冲突，可清空 Word 默认模板重新生成。
